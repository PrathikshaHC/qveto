POST /api/predict

Accepts an email body and returns risk scores and token attribution.

Request Body (JSON):
{
  "sender": "service@paypal-alerts.com",
  "subject": "Urgent verification required",
  "body": "Please click here to verify your bank credentials immediately."
}
JavaScript Fetch (Frontend)
const res = await fetch("http://127.0.0.1:5000/api/predict", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    text: "Urgent: verify your account http://bit.ly"
  })
});
const data = await res.json();
console.log(data.prediction, data.phishing_probability);
Python Client Example
import requests

url = "http://127.0.0.1:5000/api/predict"
payload = {
    "text": "Your account is locked. Click here to verify."
}
response = requests.post(url, json=payload)
data = response.json()

print(data["prediction"])            # 'Phishing'
print(data["phishing_probability"])  # 0.9994
cURL CLI Example
curl -X POST http://127.0.0.1:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"text": "URGENT: Verify your account immediately http://bit.ly/login"}'
